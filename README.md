# PB-SEM-III Portfolio

This repository contains my assignments and code for SEM-III.

### How to compile and run the programs:

* **C Program (`hello.c`):** 
  `gcc hello.c -o hello && ./hello`

* **Python Program (`hello.py`):** 
  `python hello.py`

* **Java Program (`largestno.java`):** 
  `javac largestno.java && java largestno`
